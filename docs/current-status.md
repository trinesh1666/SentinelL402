# SentinelL402 — Current Project Status

## 1. Project Overview

SentinelL402 is an AI-powered security and metered API platform that combines:

- AI agent capabilities
- Machine-learning-based network security analysis
- FastAPI backend APIs
- API-key authentication
- Multi-user usage isolation
- HTTP 402 / L402 payment flow
- Lightning payment integration
- Usage credits and metering
- Live monitoring
- Web dashboard
- Ollama-based LLM integration
